# 解法2: in-place 2ポインタ法
時間計算量: O(n)
空間計算量: O(1)

新しく配列を作らずにポインタで英数字であるものだけを見ていくため追加のメモリがいらない。
ただ、NeetCodeにそれぞれの解法で提出すると解法1の方が時間計算量が小さく、実行に必要なメモリは同じだった。理由としては、
解法2ではwhileループをネストしているため、構造が複雑なことから合計自体はO(n)でも命令実行回数は多くなりがちになる。
対して、解法1では単純なループを2つ書いていて処理も軽いことからこのような結果が得られたと考えられる。
